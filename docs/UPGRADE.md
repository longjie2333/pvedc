# 管理平台升级验收清单

本轮在 `dev` 分支实施，每项独立提交。以本地代码覆盖 PVE 部署，保留正式数据、配置及主密钥，不合并主分支。

## 功能与验证

- [ ] coss 组件审查：表单、弹窗、Checkbox、独立开关设置块、键盘及移动端。
- [ ] Toast：操作结果、复制与导入导出、任务提交及最终状态，轮询去重。
- [ ] OTP Field：全部 TOTP 流程自动提交、防重、失败聚焦及保存密钥确认。
- [ ] 我的学号 Combobox：远程搜索、名单限定、选中项保留。
- [ ] 双 token：一小时访问、七天绝对期限、轮换并发、撤销、前端续期。
- [ ] 任务与审计：服务端分页、查询栏、学生隔离、总览移除整批任务。
- [ ] gost 配置迁移至公网转发，分区保存。
- [ ] gost API 宿主同步：持久化任务、受限 helper、重启验证、失败回滚及中断恢复。
- [ ] 按需显示/复制 API Basic Auth，禁止普通响应、审计和日志泄露凭据。
- [ ] Relay Web 监听支持 0.0.0.0，部署说明使用有效访问地址。
- [ ] PVE 网络/存储/模板选择；NAT 自动命名；规格 Combobox 预设及自定义。
- [ ] 宿主状态、存储及一小时性能曲线。
- [ ] 学生全选反选、批量电源/回收/删除；删除自动清理机器及转发。
- [ ] 结构化监听端口；管理员进程名/PID；学生隐藏表格、对象 Select 与手动端口。
- [ ] 本地构建、类型、集成测试及浏览器验收。
- [ ] 隔离真实 PVE/gost 联调；备份、部署、正式数据和链路只读复核。

## 固定产品决策

- 两端登录最长七天，从首次登录计算；访问 token 一小时，刷新轮换。
- 全选/反选作用于当前搜索结果，改搜索条件清空选择。
- 批量包含启动、关机、重启、回收、删除；删除自动回收，不增加批量改密或重建。
- 新 NAT 自动创建 VNet；桥接选已有网桥/VNet。
- 学生转发可选监听服务，也可手动填写协议和端口。
- 每个开关单独成块，输入框与开关分区。
- API 调用凭据为 `Authorization: Basic Base64(username:password)`，明确标注编码。
- 线上代码差异不并入本地；不支持的历史任务只读展示。
