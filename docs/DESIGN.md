## Overview

PVE Distribution Center 是 PVE LXC 自助分配平台：管理员管理名单、资源配置、网络与公网转发，学生认领学号后创建并管理自己的容器。界面是中性的运维后台，基于 coss ui（Base UI）与 Tailwind CSS v4。布局先于文字：层级、分组和位置本身说明内容，只保留说明后果或口径的文字（如「同步会重启服务」「估算不限制创建」）。

## Colors

- `primary` 是唯一强调色，只用于主按钮、选中态、Meter、链接和图表首色；背景、卡片和边框保持中性。
- 文字、边框和填充色（`foreground`、`muted-foreground`、`border`、`input`、`muted`）与品牌绿同属暖橄榄色系。页面和侧栏底色（`background`、`sidebar`）不随之着色，卡片内的层次只靠表头浅底和分隔线区分。
- 状态色与品牌色解耦：`success` 表示完成或运行，`info` 表示进行中，`warning` 表示需要处理，`destructive` 表示失败或危险；文字和徽标使用对应的 `-foreground`。
- 生命周期状态统一由 `Status` 组件映射，不在调用处直接写颜色：
  - success：已就绪、运行中、已完成、监听中
  - info：已预留、创建中、初始化中、重建中、回收中、排队中
  - warning：需要处理、待应用、已暂停
  - error：失败、不可用
  - secondary（默认）：已停止、已关闭、状态未知，以及未登记的文本状态
- 非生命周期标签（协议 TCP/UDP、已认领/未认领）用 outline 或 secondary Badge，不带状态圆点。
- 需要处理的数量大于 0 时（KPI、侧栏导航徽标）数值改用 warning 色；接近上限的 Meter 指示条同样改用 warning。
- 图表系列依次使用 `chart-1` 到 `chart-4`：品牌绿、青蓝、琥珀、陶土。
- 登录页品牌面板使用一组只在该面板内生效的暖深绿配色，不进入全局变量。
- 更换品牌时同时替换 `primary`、`ring`、`chart-1` 和登录面板配色，并把中性色的色相调到与品牌色相邻。

## Typography

- 正文、控件和标题都用 `sans`，标题只靠字号与字重区分。
- IP、端口、学号/ID、MAC、命令、卷 ID 用 `mono`。
- 数字列和指标值必须使用等宽数字（`tabular-nums`）。
- 管理端页面标题由顶栏面包屑当前项承担，字号与正文一致；学生端页面标题是内容区顶部的 h1。
- 详情页的实体标题（如机器名）和指标值是页面内最大的文字；卡片标题次之；表单分组标题与正文同号、加粗。
- 次行、说明和时间等辅助信息用小一号字和 `muted-foreground`。
- 登录页主标语和表单标题使用专属的大字号与收紧字距，只在登录页出现。

## Layout

### 外壳

管理端与学生端使用不同外壳，不共用同一套导航。

- 管理端：coss Sidebar 的 inset 外壳，内容是浮在侧栏底色上的白色圆角面板。
  - 侧栏头放品牌图标和平台名称，名称取自平台设置。侧栏底只放账户菜单，菜单内放退出登录。
  - 导航按用途分组（日常 / 资源 / 运维），组之间只用留白区分，不加组名。
  - 顶栏依次放切换导航按钮、面包屑和页面操作区。面包屑当前项包在 h1 里作为页面标题，`sm` 以下隐藏首级。
  - 内容区不放标题行。页面级操作经 `HeaderActions` 渲染到顶栏右侧，主操作在最右，`sm` 以下只显示图标。
  - 进入 coss 移动断点后侧栏变为 Sheet 抽屉，点击导航链接后必须关闭抽屉。
- 学生端：吸顶半透明顶栏，依次为品牌、导航链接和账户菜单。窄屏品牌只显示图标；导航 `nav` 必须有无障碍名称。内容区比管理端更窄。
- 登录页：`lg` 及以上左右分栏，左侧品牌面板，右侧表单；`lg` 以下品牌面板缩为表单上方的标语区并隐藏特性列表。
  - 每个入口是独立路由，写自己的标题和一行说明。
  - 同一角色的多种入口（登录 / 首次认领）用 Tabs，Tab 由 URL 决定、切换即导航。另一角色的入口放在表单下方，用链接样式按钮导航。
  - 无 Tab 的入口（首次初始化、二次验证）只显示标题、说明和表单。

### 页面模板

- 总览：条件提示 → KPI 条（一张卡片分四格，`md` 以下两列）→ 主图卡与容量卡并排（`lg` 以下上下排列）→ 主表。容量卡不撑高行，条目多时在卡片内滚动。
- 列表页：卡片顶部工具行左侧为筛选，右侧为搜索（窄屏占满一行）。表格首列复选框，末列行菜单。数据量在几百条以内且需要「全选当前结果」时一次加载、前端筛选，不分页。
- 卡片网格页：参数是短数字的卡片在宽屏排三列，参数含长地址的卡片最多两列。卡片头放名称、一行描述和状态徽标；卡片体用 `dl` 列出参数；卡片底按钮依次为编辑（outline）、主操作（default）、次要或危险操作（ghost）。口径说明放在网格下方。
- 详情页：实体卡头放标题、状态和一行事实（ID、规格、运行时长），右侧放操作；卡体用 `dl`，可复制的值后跟复制按钮。指标卡上部为标签和数值，下部为贴边的最近一小时迷你图。
- 设置页：每个设置分组一张卡片，字段两列，开关在字段下方。保存按钮放在右下角吸底的紧凑浮动条里，不横跨整页；不同功能区分别保存，只提交本区字段。
- 编辑器页：一张卡片内左侧列表、右侧编辑区，窄屏改为上下排列且列表限高滚动。

### 排版规则

- 页面内容一律放在卡片中，区块之间使用统一间距。
- 表格作为卡片直接子元素时，首末列由全局规则与卡片内边距对齐，调用处不再单独加内边距。同一卡片里的筛选区和分页条与之对齐。
- 被多处复用、宽度不由视口决定的组件（实体卡、指标卡网格）用容器查询排版，不用视口断点。Tailwind v4 写作 `@md:`（≥）与 `@max-md:`（<）。
- 网格列写 `minmax(0, 1fr)`，避免长文本撑宽容器；fieldset 和 Select 放进弹窗或窄列时加 `min-w-0`。
- 宽表格在自身容器内横向滚动，页面本身不得出现横向滚动。

## Elevation & Depth

层次主要靠边框和表头浅底表达，卡片只带极轻的阴影。浮动的批量操作条、吸底保存条和弹窗使用更深的阴影，浮在内容之上。

## Shapes

卡片和弹窗圆角最大，子卡片和浮动条次之，按钮、输入框和菜单最小。状态徽标前带一个小圆点。

## Components

### 卡片

- 用 coss `Card`；通用 `Panel` 提供标题、描述和右侧操作。卡片头下方直接接表格时，卡片头加下边框，卡片裁切溢出，让表头随卡片圆角一起裁切。
- 卡片标题与页面标题或 Tab 名重复时省略标题，只保留卡片容器。
- 卡片描述只写会影响操作判断的信息。
- 卡片的操作按钮由页面以 children 组合。

### 表格

- 表头用浅底与白色表体区分，表头上方要有一条分隔线（由卡片头、工具行或筛选区提供）。
- 双行单元格主值在上，次值用辅助字号在下（姓名 / 学号、规格 / 网卡数）。
- 地址、端口和 ID 列用 `mono` 小号字；数值列用等宽数字；缺省值显示「—」。
- 选中行设 `data-state="selected"`，底色由表格组件提供。

### 按钮与菜单

- 每个区域最多一个 default 按钮；次要操作用 outline；行内和工具条用 ghost。
- 危险操作入口用 `destructive-outline` 或菜单内的 destructive 项，执行按钮放在确认弹窗里，使用 destructive。
- 卡片头和工具条里的按钮用小尺寸。
- 行操作统一收入「⋯」菜单，危险项放在分隔线之后。
- 互相关联的一组操作（关机 / 重启）用 `Group` 连在一起，按实时状态只显示可执行的项；拿不到状态时全部显示，由服务端拒绝非法操作。

### 选择与切换

按语义选择原语，再套用分段外观：

| 意图 | 原语 |
| --- | --- |
| 切换内容面板 | Tabs |
| 筛选值、单选表单值 | Radio Group + 分段样式 |
| 页面导航 | 链接 + `aria-current` |
| 布尔设置 | Switch（放在 `SwitchSetting` 块内） |
| 少量固定选项 | Select |
| 需要搜索或自定义输入 | Combobox |

页面级 Tab 的值取自 URL，切换即导航。

### 表单

- 字段统一由 Field、标签、控件和说明或错误组成；有表头或前置标签的紧凑行把标签设为仅读屏可见，不删除标签。
- 弹窗和长表单按用途分组（`FormSection`），组与组之间用分隔线，组内两列网格，窄屏单列。
- 可增删的行（网卡、端口规则）：行首等宽标签，中间控件，行尾上移、下移、删除按钮；多列时加一行 `aria-hidden` 表头，每个输入框使用逐行的无障碍名称；小屏改为两行。
- 每个开关独立成块（标签 + 一行说明 + 右侧开关），集中放在「选项」组，不与输入框混排。
- 多条校验错误合并为一个 error Alert，内含列表；有错误时禁用保存按钮。
- 只在依赖项满足时才有意义的字段（如非主网卡的网关）直接隐藏，不显示禁用框。

### 弹窗

- 普通编辑用 Dialog，破坏性操作（包括删除单个对象）用 AlertDialog；底部为「取消（ghost）+ 主操作」。
- 弹窗描述写清后果（「修改仅影响后续分配」「此操作将永久清空系统盘数据」）。
- 不可恢复的批量操作要求输入与所选数量绑定的确认短语（如「删除 3 名学生」），输入一致前禁用确认按钮。
- 需要中断服务的变更（运行中改网络）先确认，说明会关机、应用、再启动。

### 反馈

| 场景 | 组件 |
| --- | --- |
| 区域内持久的错误或成功 | `Feedback`（Alert） |
| 操作完成、后台任务结果、复制 | Toast，按任务 ID 去重合并 |
| 系统未就绪、需要配置 | info Alert + 跳转按钮 |
| 空数据 | `Empty`：图标 + 一句标题，只有首次引导才加一句说明 |
| 加载 | Loading 或 Skeleton，不插入造成跳动的占位框 |

空结果的标题写「没有匹配的 X」，不加建议文案。

### Meter 与图表

- 有上下限的量（CPU、内存、磁盘、地址池）用 coss Meter，标签与「已用 / 总量」同一行，数值右对齐。
- 趋势图用 recharts 面积图：只画水平网格线，坐标轴无轴线、无刻度线，面积为同色向下渐隐，关闭动画。
- 多个指标用卡片头部的 Tabs 切换，不平铺多张图；同一图中有多个系列时才显示图例。
- 迷你图贴卡片左右和底边，无坐标轴。有总量的指标纵轴取 0 到总量，面积高度就是占用比例。同一页面的渐变 id 必须唯一。
- 悬停提示统一用 `ChartTooltip`：上方采样时间，下方每个系列一行。
- 没有采样数据时显示空状态，不显示空坐标系。

### 批量选择

- 表头复选框选中当前筛选与搜索结果，部分选中显示 indeterminate；修改搜索或筛选时清空选择。
- 有选择时在列表下方出现吸底的 `role="toolbar"` 操作条，依次为已选数量、反选、设置类菜单、同类操作菜单、危险操作和清空选择。
- 设置类菜单点选即生效，错误用 Toast 提示；危险操作进入确认弹窗。
- 受理结果用列表下方的一张结果卡逐项展示「已提交 / 已跳过 / 未受理」及原因，并给出任务记录入口。

### 敏感值

- 密钥、认领码在列表中默认遮盖，逐行点击显示或隐藏；导出文件仍包含完整值。
- 凭据（如 API 调用头）只在用户点击「显示」时单独向服务端读取，离开页面不缓存。

### 引导信息

学生最先需要的说明（使用指南、连接方式）放在工作台最上方，默认展开未标记为折叠的篇目；没有内容时整块不显示。

## Writing

- 页面标题和卡片标题用名词（「学生名单」「容量」「公网转发」）；按钮用动词或动宾（「导入名单」「关机并应用调整」）。
- 确认按钮写明动作，如「确认删除学生」。
- 状态文字两到四个字；错误信息说明原因和下一步（「可用 VMID 已用尽，请调整平台设置中的 VMID 范围」）。
- 数量与单位之间留空格（「32 GiB」「2 核」）；比例写作「41 / 55」，分母用常规字重和次要色；缺省值用「—」。
- 同一信息只出现一次：页面标题、面包屑、Tab 名和卡片标题不重复同一个词。

## Accessibility

- 每页一个 h1；卡片标题渲染为 h2。
- 区块用 `section` 加 `aria-labelledby` 或 `aria-label`，成为可定位的 region（如「指导书」「网卡 eth0」）。
- 仅图标的按钮必须有包含操作对象的 `aria-label`（「操作 陈思远」「复制公网入口」「上移 eth1」）；装饰图标和底纹设 `aria-hidden`。
- 当前导航项和列表当前项用 `aria-current`；切换按钮用 `aria-pressed`。
- 错误用 `role="alert"`，非紧急结果用 `role="status"`。
- 所有交互都能用键盘完成；菜单、弹窗和 Combobox 使用 Base UI 原语自带的焦点管理。

## Do's and Don'ts

- Don't 写眉标、页面副标题、「在这里管理 X」类描述、页脚口号或与标签重复的占位符。
- Don't 在登录页放英文眉标、页脚和图标块。
- Don't 在管理端侧栏放头像和标语，也不给导航分组加组名。
- Don't 在 KPI 中用其他字段推算后端没有提供的数据。
- Don't 用 Tabs 做筛选或导航。
- Don't 用 `window.confirm` 确认删除。
- Don't 让吸底保存条横跨整页遮挡表单。
- Don't 自定义 `.panel` 之类的卡片样式替代 coss Card。
